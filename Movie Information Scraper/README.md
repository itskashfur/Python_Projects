# 🎬 Movie Information Scraper

A lightweight and efficient Python tool designed to fetch rich cinematic details directly from **IMDb**. Simply provide a movie title, and let the scraper harvest the relevant data for you.

---

## 📦 Prerequisites

Before running the script, ensure you have the necessary dependencies installed. This project relies on the following core Python packages:

* **[BeautifulSoup4](https://pypi.org/project/beautifulsoup4/)** — For parsing HTML and navigating the web structure.
* **[Requests](https://pypi.org/project/requests/)** — For handling reliable HTTP requests.

### Quick Setup

You can install all required external modules seamlessly via `pip`:

```bash
pip install -r requirements.txt
