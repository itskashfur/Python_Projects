<h1 align="center">Capture Screenshot Utility</h1>

<p align="center">
  <img src="https://img.shields.io/badge/Python-3.14-blue.svg" alt="Python Version">
  <img src="https://img.shields.io/badge/License-MIT-green.svg" alt="License">
</p>

<p>A simple, lightweight Python application that allows users to capture their screen instantly using a graphical interface. This tool is perfect for developers looking to understand GUI automation and image processing in Python.</p>

<hr />

<h2>🚀 Features</h2>
<ul>
  <li><b>Instant Capture:</b> Take a full-screen screenshot with a single click.</li>
  <li><b>User-Friendly GUI:</b> Built with Tkinter for a clean and simple interaction.</li>
  <li><b>Auto-Save:</b> Automatically saves images to your local directory.</li>
</ul>

<h2>🛠️ Dependencies</h2>
<p>This project relies on the following Python libraries:</p>
<ul>
  <li><code>Tkinter</code>: For the graphical user interface (Standard Library).</li>
  <li><code>PyAutoGUI</code>: To handle the screen capture functionality.</li>
</ul>

<h3>Installation</h3>
<pre><code>pip install pyautogui</code></pre>

<hr />

<h2>💻 Usage</h2>
<ol>
  <li>Clone the repository:
    <pre><code>git clone https://github.com/itskashfur/Python_Projects.git</code></pre>
  </li>
  <li>Navigate to the project folder:
    <pre><code>cd "Capture Screenshot"</code></pre>
  </li>
  <li>Run the application:
    <pre><code>python main.py</code></pre>
  </li>
  <li>Click the <b>"Capture"</b> button to save your screenshot!</li>
</ol>

<hr />

<h2>📝 Note</h2>
<blockquote>
  The current version saves screenshots in the root folder where the script is executed. Make sure you have write permissions for that directory.
</blockquote>
