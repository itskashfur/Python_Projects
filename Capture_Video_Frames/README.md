# 🎥 Capture Video Frames

A streamlined Python utility for capturing frames from local video files, streaming live webcam feeds, and integrating with AWS Kinesis Video Streams.

---

## 🚀 Quick Start Guide

### 1. Capture Frames from a Video File
Extract individual frames from any local video file using the following command:

> [!TIP]
> Replace `<video_file>` with the path to your actual file (e.g., `my_video.mp4`).

```bash
python capture_video_frames.py <video_file>
