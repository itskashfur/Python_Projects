# 📂 Convert JSON to CSV

A lightweight, efficient Python script that takes a `JSON` file as input and seamlessly generates a clean `CSV` file output. Perfect for data flattening and quick migrations!

---

## 🚀 Getting Started

### Prerequisites
This script uses **Python 3** and its built-in modules. 

> 💡 **Note on Dependencies:** The `json` and `csv` modules are part of Python's standard library. **You do not need to install them via pip.** If you are missing Python entirely, make sure you have Python 3 installed on your system.

---

## 🛠️ How to Run the Script

Follow these simple steps to convert your files:

1. **Prepare your input:** Make sure your source data is saved as `input.json` in the same directory as the script.
2. **Execute the script:** Run the following command in your terminal or command prompt:

   ```bash
   python3 converter.py
